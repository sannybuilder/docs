# Debugger

Here you can change some debugger settings.

<div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>

### Game Executable

A path to the main executable. For San Andreas, for example, it is usually called `gta_sa.exe`.

### Arguments

Additional values given to command line when the debugger launches the process. Syntax and naming are game-dependent.
