# 0108: Unsupported argument type

Compiler expected a known type of the parameter in the function signature, but provided name is not known.

E.g. in

```pascal
function foo(value: something)
```

`something` might not be a valid type. Compiler expects `int`, `float`, `string` or a [class](../../language/instructions/classes.md) name (e.g. `Player`).

#### Possible solution:

* use a valid type name. Check [Function](../../language/functions.md#signature) documentation for more information.
