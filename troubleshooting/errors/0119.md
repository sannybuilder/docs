# 0119: Unsupported type of argument

Compiler found a value that is not supported as a command argument. It can be, for example, a function call

```pascal
wait foo()

function foo(): int
  return 100
end
```

As of version 4.0 Sanny Builder does not support expressions as arguments. Each argument must be a literal (number or string), or a variable.

#### Possible solutions:

* store function call's result in a variable, then pass variable to command as an argument:

```pascal
int delay = foo()
wait delay

function foo(): int
  return 100
end
```
